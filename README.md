# Intrusion Detection and Prevention System (IDPS)

## Overview
The **Intrusion Detection and Prevention System (IDPS)** is a cybersecurity solution designed to monitor, detect, analyze, and prevent malicious activities within a network or system. The project enhances system security by identifying suspicious traffic and automatically blocking potential threats in real time.

This project combines:
- **Intrusion Detection System (IDS)** → Detects attacks and suspicious behavior
- **Intrusion Prevention System (IPS)** → Prevents and blocks malicious activities

---

# Features

- Real-time network traffic monitoring
- Signature-based attack detection
- Anomaly-based threat analysis
- Automatic IP blocking and prevention
- Packet sniffing and filtering
- Alert generation and logging
- Firewall integration support
- Dashboard for monitoring
- Lightweight and scalable design
